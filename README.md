# CafeBot

A small starter structure for a cafe chatbot project. This repository currently contains organization and notes only; the application has not been built.

## Project folders

- `prompts/` — drafts and reusable instructions for the chatbot.
- `data/` — sample or development data. Keep private customer information out of this folder.
- `frontend/` — future code for the part customers interact with.
- `backend/` — future code for chatbot logic and server-side work.
- `env/` — safe environment variable examples. Copy `env/.env.example` to `env/.env` for local secrets when needed; never commit `.env`.

## Getting started

No installation or paid services are needed for this starter structure. There is no application to run yet. Add tools and services only when the next project step requires them.
